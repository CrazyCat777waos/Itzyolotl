# Herramientas

## tailwindcss.exe

CLI independiente de Tailwind CSS (versión 4.3.5). No se sube a Git.

Descargar desde la raíz de la solución:

    mkdir tools -Force
    Invoke-WebRequest -Uri "https://github.com/tailwindlabs/tailwindcss/releases/download/v4.3.5/tailwindcss-windows-x64.exe" -OutFile tools/tailwindcss.exe
